# 🔧 Prompt Engineering Cheat Sheet

Your quick reference guide for effective prompt engineering. Bookmark this page for instant access to templates, patterns, and best practices.

## 🎯 Quick Prompt Formula

```
[ROLE] + [TASK] + [CONTEXT] + [FORMAT] + [TONE] = Effective Prompt
```

### Example Application
```
[Marketing Expert] + [Write product description] + [for eco-friendly toothbrush, target: environmentally conscious families] + [2 paragraphs, include benefits and call-to-action] + [persuasive but trustworthy] = Complete Prompt
```

## 📋 Essential Prompt Templates

### 1. Content Creation Template
```
Write a [TYPE] about [TOPIC] for [AUDIENCE].

Requirements:
- Length: [WORD COUNT]
- Tone: [TONE]
- Include: [KEY POINTS]
- Format: [STRUCTURE]
- Call-to-action: [CTA]

Additional context: [BACKGROUND INFO]
```

### 2. Analysis Template
```
Analyze [SUBJECT] from the perspective of [ROLE/EXPERTISE].

Focus on:
- [ASPECT 1]
- [ASPECT 2] 
- [ASPECT 3]

Provide:
- Key insights
- Supporting evidence
- Actionable recommendations
- [SPECIFIC DELIVERABLE]

Context: [SITUATION/BACKGROUND]
```

### 3. Problem-Solving Template
```
Help solve this [PROBLEM TYPE]:

Problem Statement: [CLEAR DESCRIPTION]
Current Situation: [CURRENT STATE]
Desired Outcome: [GOAL]
Constraints: [LIMITATIONS]
Resources Available: [RESOURCES]

Provide:
1. Root cause analysis
2. 3+ solution options
3. Implementation steps
4. Success metrics
5. Risk mitigation
```

### 4. Creative Template
```
Create [CREATIVE OUTPUT] that includes:

Required Elements:
- [ELEMENT 1]
- [ELEMENT 2]
- [ELEMENT 3]

Style: [CREATIVE STYLE]
Audience: [TARGET AUDIENCE]
Constraints: [LIMITATIONS]
Inspiration: [REFERENCE POINTS]

Make it [DESIRED QUALITIES].
```

### 5. Technical Template  
```
[TECHNICAL TASK] using [TECHNOLOGY/LANGUAGE].

Specifications:
- [REQUIREMENT 1]
- [REQUIREMENT 2]
- [REQUIREMENT 3]

Include:
- Error handling
- Documentation/comments
- Best practices
- [SPECIFIC TECHNICAL REQUIREMENTS]

Target: [SKILL LEVEL] developers
```

## 🔍 Question Frameworks

### The 5W+H Framework
```
- Who: Who is involved/affected?
- What: What needs to be done/understood?
- When: What are the timing considerations?
- Where: What is the context/location?
- Why: What is the purpose/motivation?
- How: What is the method/approach?
```

### The SCAMPER Method (for creative prompts)
```
- Substitute: What can be substituted?
- Combine: What can be combined?
- Adapt: What can be adapted?
- Modify: What can be modified/magnified?
- Put to other uses: How else can this be used?
- Eliminate: What can be removed?
- Reverse: What can be rearranged/reversed?
```

### The SWOT Analysis Framework
```
Analyze [SUBJECT]:
- Strengths: Internal positive factors
- Weaknesses: Internal negative factors  
- Opportunities: External positive factors
- Threats: External negative factors

Provide strategic recommendations based on this analysis.
```

## 🎨 Tone and Style Guide

### Professional Tones
```
- Authoritative: "Drawing from extensive research and industry expertise..."
- Consultative: "Let's work together to identify the best approach..."
- Educational: "Here's what you need to know to understand..."
- Analytical: "The data reveals several key patterns..."
```

### Casual Tones
```
- Conversational: "Let's chat about this interesting topic..."
- Friendly: "I'd love to help you figure this out..."
- Encouraging: "You're on the right track, and here's how to..."
- Humorous: "Here's the deal (and why it's actually pretty funny)..."
```

### Persuasive Tones
```
- Compelling: "The evidence clearly demonstrates that..."
- Urgent: "Time is critical, and here's what you need to do..."
- Inspiring: "Imagine the possibilities when you..."
- Reassuring: "You can feel confident that this approach..."
```

## 📊 Output Format Specifications

### Structured Formats
```
- "Format as a numbered list with brief explanations"
- "Create a table with columns for [A], [B], and [C]"
- "Structure as: Introduction, 3 main points, conclusion"
- "Present as a step-by-step process with sub-steps"
```

### Length Specifications
```
- "In exactly 100 words"
- "2-3 paragraphs, approximately 300 words"
- "A comprehensive 1,500-word analysis"
- "A brief summary in 3-5 bullet points"
```

### Style Specifications
```
- "Use bullet points and short paragraphs for readability"
- "Write in active voice with strong action verbs"
- "Include relevant statistics and specific examples"
- "End with 3 actionable next steps"
```


### Chain-of-Thought Pattern
```
Let's think through this step by step:

Step 1: [FIRST REASONING STEP]
Step 2: [SECOND REASONING STEP] 
Step 3: [THIRD REASONING STEP]
...
Conclusion: [FINAL ANSWER WITH REASONING]
```

### Perspective-Taking Pattern
```
Consider this from multiple perspectives:

Perspective 1 ([STAKEHOLDER 1]): [THEIR VIEW]
Perspective 2 ([STAKEHOLDER 2]): [THEIR VIEW]
Perspective 3 ([STAKEHOLDER 3]): [THEIR VIEW]

Synthesis: [BALANCED CONCLUSION]
```

## 🚫 Common Mistakes to Avoid

### ❌ Don't Do This
```
❌ "Write about AI" (too vague)
❌ "Make it good" (subjective, no criteria)
❌ "Help me with everything" (overwhelming scope)
❌ "Fix this" (no context provided)
❌ "Be creative" (no direction or constraints)
```

### ✅ Do This Instead
```
✅ "Write a 500-word explanation of AI for small business owners"
✅ "Improve clarity, add specific examples, maintain professional tone"
✅ "Help me create a social media strategy for my local bakery"
✅ "Fix this Python function that should calculate compound interest"
✅ "Generate 5 creative marketing taglines for eco-friendly products"
```

## 📈 Quality Checklist

Before submitting any prompt, check:

### ✅ Clarity
- [ ] Is the task clearly defined?
- [ ] Would someone else understand what I want?
- [ ] Are there any ambiguous terms?

### ✅ Context
- [ ] Have I provided necessary background?
- [ ] Is the audience/purpose clear?
- [ ] Are constraints and requirements specified?

### ✅ Completeness
- [ ] Have I included all necessary information?
- [ ] Is the desired output format specified?
- [ ] Are success criteria defined?

### ✅ Conciseness
- [ ] Is every word necessary?
- [ ] Can I remove redundancy without losing meaning?
- [ ] Is the prompt as efficient as possible?

## 🔧 Troubleshooting Guide

### Problem: Generic/Vague Responses
**Solution**: Add more specific requirements, examples, and context

### Problem: Wrong Tone/Style
**Solution**: Explicitly specify tone and provide example language

### Problem: Incorrect Format
**Solution**: Use detailed format specifications and examples

### Problem: Incomplete Information
**Solution**: Break down requirements into specific, checkable items

### Problem: Inconsistent Results
**Solution**: Add more constraints and reduce ambiguity

## 📱 Mobile-Friendly Quick Reference

### Essential Elements (CTFTR)
- **C**ontext: Who, what, where, when, why
- **T**ask: Specific action required
- **F**ormat: How output should be structured
- **T**one: Style and voice
- **R**equirements: Constraints and specifications

### Quick Quality Check (CLEAR)
- **C**lear: Unambiguous instructions
- **L**ogical: Sensible structure and flow
- **E**xample: Includes examples or patterns
- **A**udience: Target audience specified  
- **R**elevant: Addresses the actual need

## 🎯 Emergency Prompt Fixes

### When Your Prompt Isn't Working:

1. **Add Specificity**: Replace vague terms with precise requirements
2. **Provide Examples**: Show what good output looks like
3. **Set Constraints**: Add word limits, format requirements, tone guidelines
4. **Include Context**: Explain the situation and purpose
5. **Break It Down**: Split complex requests into smaller parts

### Quick Fixes by Problem Type:

| Problem | Quick Fix |
|---------|-----------|
| Too generic | Add specific requirements and examples |
| Wrong audience | Specify target audience and their needs |
| Poor format | Include detailed formatting instructions |
| Inconsistent quality | Add constraints and evaluation criteria |
| Missing context | Provide background and purpose |
